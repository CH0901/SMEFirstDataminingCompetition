# 캐글 제출 절차

마감: **2026년 8월 23일(일) 23:59 KST**
채점: 2026년 8월 26일 ~ 30일, 매일 14시(KST), 96지점 × 5일 = 480행

제출물은 **두 개**이며 둘 다 마감 전에 끝내야 한다.

| | 제출물 | 어디에 |
|---|---|---|
| ① | 추론 노트북 + 모델 Dataset | 캐글 |
| ② | 학습 코드 `.ipynb` | 구글폼 |

---

## 1단계 — 모델을 캐글 Dataset 으로 올리기

올릴 파일: **`model.pkl`** (약 105MB)

> 이미 `chaehyeonm/model1` Dataset 이 있으므로, 새로 만들지 말고
> 그 Dataset 에서 **`New Version`** 으로 올린다. 버전을 갱신하면
> 노트북의 Input 을 **반드시 다시 연결**해야 최신 파일이 잡힌다.

1. https://www.kaggle.com/datasets 접속 → **`New Dataset`**
2. `model.pkl` 을 끌어다 놓기
3. **Title**: 팀명이 들어간 이름 (예: `sme-gk2a-model`)
4. **Visibility**: **Public** ⚠️
   - Private 이면 운영진이 복제할 때 접근이 안 되어 **실행 실패**
   - 규칙 4.1 ③ 에 명시됨
5. **Create**

> 대회 종료 전 코드 공개는 금지지만, 모델 가중치 Dataset 은 Public 이 요구사항이다.
> 코드(노트북)만 Private 으로 유지하면 된다.

---

## 2단계 — 추론 노트북 만들기

1. 대회 페이지 → **`Code`** 탭 → **`New Notebook`**
2. **File → Import Notebook** → `submission_notebook_filled.ipynb` 업로드 (새 양식 `submission_notebook_2` 기반)
   - 또는 새 노트북에 셀을 직접 붙여넣기
3. 오른쪽 **Input** 패널에서 **`+ Add Input`**
   - 대회 데이터 (`station_list.csv`) 추가
   - 1단계에서 만든 모델 Dataset 추가
4. 오른쪽 **Session options**
   - **Internet: On** ⚠️ (없으면 위성 API 호출 불가)
   - Accelerator: None (GPU 불필요)
   - Persistence: No persistence

### 셀 1 에서 채울 것

```python
API_KEY    = "본인의_인증키"     # ← 여기만 입력
PRED_START = "20260624"        # ← 그대로 두기 (운영진이 교체)
PRED_END   = "20260630"        # ← 그대로 두기
```

- `API_KEY` 는 **코드에 직접** 입력. Kaggle Secrets 사용은 규칙 위반
- 날짜는 손대지 않는다. 운영진이 8/26~30 으로 바꿔 실행한다

## 3단계 — 실행 확인

**`Run All`** 로 끝까지 돌려본다. 정상이면 이런 출력이 나온다.

```
예측 기간 : 20260624 ~ 20260630  (7일)
평가 지점 : 96개
h5py 3.14.0 — GK2A(HDF5) 판독 준비 완료
모델 로드 완료 — 채널 ['IR105', 'IR123', 'SW038'], 피처 151개
위성 요청 126건 (7일 x 6시각 x 3채널)
1차: 성공 ...
다운로드 최종 성공 126 / 126
예측 완료 672행
  저장 완료: /kaggle/working/submission.csv
  672행 = 96지점 x 7일
```

### 날짜 교체 리허설 (반드시)

`PRED_START` / `PRED_END` 를 **다른 기간**(예: `20260810` ~ `20260816`)으로 바꿔
`Run All` 을 한 번 더 돌린다. **운영진 채점과 똑같은 상황**이다.
여기서 에러가 나면 채점이 불가능하다.

확인 후 날짜를 **원래대로 되돌린다.**

## 4단계 — 동결 (Save Version)

1. 오른쪽 위 **`Save Version`**
2. **Version Type: `Save & Run All (Commit)`** ⚠️
   - **`Quick Save` 는 동결로 인정되지 않는다** (규칙 5. 실격 사유)
3. Version Name: `final_submission`
4. **Save**

저장 후 **Versions** 탭에서 저장 시각을 확인한다. 표시는 UTC 이며
**KST = UTC + 9시간**. 마감(8/23 23:59 KST)은 UTC 로 **8/23 14:59** 이다.

---

## 5단계 — 운영진 공유

1. 노트북에서 **`Share`**
2. 노트북 자체는 **Private 유지** (대회 종료 전 공개 금지)
3. 운영진 계정을 검색해 **Collaborator** 로 추가
   - 권한은 **`Can edit`**
4. **Save**

- **실행 출력이 남아 있는 상태**로 저장되어 있어야 한다 (이미 그렇게 만들어 둠)
- 채점 대상은 아니고 코드 검증용

## 규칙 2.1~2.3 (개정판) 대조

**2.1 허용 입력** — 우리 모델의 피처가 정확히 이 범위 안에 있다.

| 규칙이 허용하는 것 | 우리 사용 | 개수 |
|---|---|---|
| GK-2A LE1B 채널 (영역 KO) | IR105, IR123, SW038 의 창 통계와 그 파생 | 228 |
| `station_list.csv` 위도·경도·고도 | LAT, LON, HT | 3 |
| 날짜·좌표에서 계산되는 값 | 연중일 sin/cos, 위성 천정각, 연도 | 4 |
| 위 항목들끼리의 조합 | 전국 편차·이웃·방향별 이웃 | (파생) |
| 그 외 | **없음** | 0 |

**2.2 금지 입력** — 해당 없음.

- 기후 평년값·지점별 과거 평균기온: 사용하지 않음. 모델 파일에도 없음
- 외부 정적 지리정보(DEM·토지피복·해안선 등): 사용하지 않음
- 수치예보·재분석·타 기관 자료: 사용하지 않음

**2.3 ASOS 기준** — ASOS 기온·습도는 **학습 라벨로만** 사용했다.
lag 피처로도, 저장해 둔 최근값으로도, 평가기간 조회로도 쓰지 않는다.
추론 노트북이 호출하는 URL 은 `.../GK2A/LE1B` 하나뿐이다
(새 양식의 API 감사 로그에도 그렇게 기록된다).

## 그 밖의 실격 사유 (규칙 5)

- 평가 기간 데이터를 학습·튜닝에 활용한 경우
- 마감 이후 저장된 버전만 존재하는 경우
- 제출 코드로 결과가 **재현되지 않는** 경우
- 대회 종료 전 코드를 공개하거나 공유한 경우

자동 점검으로 통과를 확인했다: LE1B 외 호출 없음, ASOS 호출 없음,
기후 평년값 미사용, 날짜 하드코딩 없음, 난수 없음, Secrets 미사용.

**재현성 확인**: `train_notebook.ipynb` 를 처음부터 실행하면 제출한
`model.pkl` 과 같은 예측을 내놓는다(최대차 0). 시드 고정과 LightGBM
`deterministic=True` 덕분이다.

**추론 환경**: 캐글은 인터넷이 켜져 있어도 pip 설치가 막힐 수 있어,
NetCDF 판독을 기본 탑재된 `h5py` 만으로 처리한다 (netCDF4 불필요).
실제로 pip 방식은 캐글에서 DNS 오류로 실패했고, h5py 방식은 같은 배열을
바이트 단위로 동일하게 읽는 것을 확인했다.
