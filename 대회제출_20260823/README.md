## 모델 구조

**선형(Ridge) + GBM 잔차.** 트리는 학습 범위 밖으로 외삽하지 못한다.
8월 자료로 학습한 GBM 단독 모델은 6월에도 "8월이니까 30도"를 내놓아
편향이 +4.3도였다. 선형항이 추세를 담당하고 GBM 은 잔차만 학습한다.

시드 3개(42, 7, 2024) 평균. `deterministic=True` 라 재실행해도 같은 결과.

**타깃마다 피처가 다르다.** 점수가 `TA + 0.1×HM` 이라 각각 최적을 쓴다.

- 기온: 연도 O, 공간 피처 O (237개)
- 습도: 연도 X, 공간 피처 X (150개) — 둘 다 습도에서는 오히려 나빴다

## 무엇이 성능을 만들었나

빼면 기온이 나빠지는 정도:

```
연중일 sin/cos       +0.459   ← 압도적 1위
공간 피처 전체         +0.184
  └ 전국 편차 ANO     +0.112
  └ 방향별 이웃        +0.029
연도                 +0.146
분리대기창 보정         +0.027
위성 채널 전체         +0.004   ← 거의 0
```

원본 위성 채널을 통째로 빼도 0.004 밖에 안 나빠진다. 성능은 **"언제인가"
(계절·연도) + "어느 지점인가" + "오늘 전국 위성 패턴이 평소와 얼마나
다른가"** 에서 나온다.

### 타깃 분해

14시 기온 분산 14.20 을 나누면:

| 성분 | 분산 | 비중 |
|---|---:|---:|
| 날짜간 (그날 기단) | 9.31 | 66% |
| 지점간 (고정 특성) | 1.31 | 9% |
| 날짜×지점 상호작용 | 3.61 | 25% |

그런데 오차를 갈라보면 **날짜 효과는 이미 거의 다 잡았다**:

```
기온 오차 1.251 = 그날수준 0.341 + 지점별 1.204
그날 전국 평균을 완벽히 안다면 → 1.204 (0.047 개선뿐)
```

남은 오차는 전부 "같은 날, 지점끼리 왜 다른가" 다. 그건 습도(−0.476)·
일사(+0.383)·지면온도(+0.373) 가 지배하는데 셋 다 입력 금지고, 위성
2km 화소를 18km 창으로 평균 내면 해안·산지 국지 구조가 뭉개진다.
최악 지점이 동해(3.47)·울진(3.02)·포항(2.76) — 전부 푄·해풍 지역이다.
